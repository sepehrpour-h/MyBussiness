# همراه

فرانت‌اند فارسی پلتفرم خدمات کسب‌وکار، ساخته‌شده با Next.js و Tailwind CSS.

## اجرا

```bash
npm install
npm run dev
```

سپس نشانی `http://localhost:3000` را باز کنید. برای بررسی نسخه تولیدی از `npm run build` استفاده کنید.

نام، محتوای مجله، خدمات و دسته‌بندی‌ها نمونه هستند. فرم تماس و جریان ورود و ثبت‌نام صرفاً نمایشی‌اند: پیامک یا پیامی ارسال، کدی تأیید، حسابی ایجاد یا داده‌ای ذخیره نمی‌شود. برای عملیاتی شدن باید به API و سرویس پیامکی متصل شوند. داده‌های نمونه در `lib/data.ts` قرار دارند.
